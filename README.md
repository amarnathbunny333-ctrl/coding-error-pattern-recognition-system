# Coding Error Pattern Recognition System

## Project Overview

The Coding Error Pattern Recognition System is an intelligent tool that analyzes source code, detects common programming errors, recognizes error patterns, and provides suggestions for fixing them.

## Features

- Syntax Error Detection
- Runtime Error Detection
- Pattern Recognition
- Error Suggestions
- Auto Fix Recommendations
- Multi-Language Support
- AI Chatbot Assistant
- Voice Explanations
- Analytics Dashboard

## Technologies Used

- Python
- Flask
- Scikit-learn
- Tkinter
- SQLite
- HTML/CSS/JavaScript
